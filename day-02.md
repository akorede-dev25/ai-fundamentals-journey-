# What I learned: the 3 eras of processing data

![Graphic](IMG_NAME.png)

## The 3 eras
- **Tabulation:** machines organize data. Chinese tax collectors used the abacus to sort tax receipts over 2,000 years ago.
- **Programming:** computers run instructions, called programs. ENIAC (1946) did calculations in 30 seconds that took 12 hours by hand.
- **AI:** machines learn from data instead of only following fixed rules.

## Rule-based systems
- An algorithm is a set of rules or step-by-step procedure that guides a machine.
- Rule-based systems follow fixed rules, like a recipe.
- They get stuck when a problem falls outside their rules.
- Branching logic explored different paths toward a goal, but still couldn't learn from data.
- This limit led to machine learning.
